## 📌 Sobre o projeto

O **Portfólio Radja Odonto** é um site institucional e profissional desenvolvido para apresentar a identidade, trajetória acadêmica, áreas de interesse, casos clínicos e canais de contato de **Radja Rodrigues**, estudante de Odontologia.

O projeto foi criado com foco em uma experiência visual moderna, elegante e responsiva, transmitindo cuidado, confiança, leveza e profissionalismo dentro da área odontológica.

---

## ✨ Destaques

- Interface moderna e responsiva
- Layout clean voltado para Odontologia
- Identidade visual profissional
- Seção de apresentação pessoal
- Área de procedimentos odontológicos
- Espaço para casos clínicos
- Botões de contato e redes sociais
- Animações suaves com Framer Motion
- Componentização com React
- Estrutura organizada e fácil de manter
